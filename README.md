# Hearsay updates

Installers and the update feed for Hearsay, a macOS meeting note-taker.

- `appcast.xml` is read by Hearsay once a day to find new versions.
- Each version's installer (`.dmg`) is attached to a release on this page.
- Every update is signed. Hearsay installs it only if the signature matches the key built into the app.

This repository holds no source code and no meeting data.

## Installing for the first time

Download the latest `.dmg` from Releases, open it, and follow "How to install Hearsay" inside.
